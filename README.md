## 使用约定

- 单位：SI（kg/m³、MPa、GPa、mm、N、N·m）。
- **公式用 LaTeX**：行内 `$...$`，独立行 `$$...$$`。在 Typora / Obsidian / VS Code（装 Markdown Math 插件）里可渲染；用普通记事本看就是 `$...$` 源码，不影响阅读。个别旧章节还有 Unicode 符号（如 `L₁₀`），意义相同。
- **图片**：插图来源：① 教材截图（互换性/机械设计/机原 PDF）；② 队里实物/装配照片（最有说服力）；③ SW 截图；④ 官方数据表截图。插入用 Markdown 语法：
  ```markdown
  ![图片说明](images/xxx.png)
  ```
  建议在 `VGD机械设计手册/` 下建 `images/` 目录，图片按 `卷号-说明.png` 命名（如 `04-曲柄摇杆极限位置.png`）。
- 数据可信度标记：
  - ✅ 有公开数据表 / 国标可查，可直接用；
  - ⚠️ 典型值，因批次 / 店铺 / 品牌而异，使用前需实测或问商家确认；
  - 🔶 经验估计值，仅用于初算，正式设计必须留安全系数。
- 安全系数（建议）：
  - 静态：金属 1.5～2；3D 打印件 2.5～4；
  - 比赛冲击 / 动态：3～5；
  - 疲劳校核：≥2。
- 手册里的公差数字基于 GB/T 1800（等同 ISO 286）、GB/T 1031、GB/T 1182，正式出图请以最新版国标表为准。

## 学习路径（先把原理吃透，再谈传承）

**建议按这个顺序学，教材章节已对应好**：

| 顺序 | 手册卷 | 对应参考 | 学到什么程度 |
|---|---|---|---|
| 1 | 卷二 互换性与公差 | 宋绪丁《互换性与几何量测量技术》极限与配合、尺寸链、形位公差、表面粗糙度章 | 会查公差表、会算尺寸链、会选配合 |
| 2 | 卷三 轴承 | 濮良贵《机械设计》第四篇"滚动轴承" | 会选轴承、算寿命、给配合公差 |
| 3 | 卷四 连杆机构 | 《机原学习笔记》/机械原理"平面连杆机构"章 | 会四杆分类、死点、急回、列矢量方程 |
| 4 | 卷五 其他传动 | 濮良贵《机械设计》第三篇"齿轮/蜗杆/带/链传动" | 会选传动、算传动比和扭矩 |
| 5 | 卷七 连接与紧固 | 濮良贵《机械设计》第二篇"螺纹连接" | 会算预紧力、选等级、防松 |
| 6 | 卷六 电机选型 | B 站《动力元件》视频 + 机械原理动力学章 + 官方数据表 | 会算负载、反推选电机 |
| 7 | 卷一 材料 | 材料手册 / MatWeb + 国标 GB/T 3880、3354、1040 | 会查证、会实测、会建 SW 材料库 |
| 8 | 卷八 出图 | 机械制图 + 工程图样国家标准 | 会画规范零件图/装配图 |

**学习建议**：
- **先公式后经验**：手册里每个公式都配了"这解决什么问题"，学的时候**亲手用队里一个真实机构算一遍**（例如算云台 pitch 的负载扭矩），比背公式有用十倍；
- **算完去验证**：算出的扭矩/变形，和 SW Motion / SW 仿真对一遍，对不上就查哪错了——这是最快的自查方法；
- **每做完一个项目，把实测数据回填进对应小节**（标来源、日期、店铺），手册才会越用越准；
- 参考 PDF（机原学习笔记、传动机构简述、互换性教材、机械设计教材）是**查公式和查表的工具书**，别通读，用到哪翻到哪。

## 维护约定

- 每新增一个材料 / 电机 / 轴承型号，在对应卷的小节追加一行，**写清楚来源和日期**；
- 实测数据、踩过的坑（淘宝假 T6、打印收缩、碳板分层）记到对应小节，这是最有价值的传承；
- 定期（每赛季）核对一次国标版本和官方电机数据表是否更新。
