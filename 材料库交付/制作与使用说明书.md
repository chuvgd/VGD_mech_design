## 二、两条制作途径，分别是怎么做的

手册 1.2 节说的两条路，我都走了一遍：

### 方法 B：直接写 XML（我这边已完成）

1. 读手册 1.2 节 B 小节给的参考模板和结构要点（命名空间、`materials → classification → material` 嵌套顺序、`matid` 连续编号、常见字段 `EX/NUXY/GXY/ALPX/DENS/KX/C/SIGXT/SIGYLD`）。
2. 把手册 1.5 节表格里每种材料的数据，**取区间中点**（没数据的字段不填、不瞎编），按模板结构逐个写成 `<material>` 节点。
3. `matid` 在全文件范围内连续编号（不是每个分类单独编号——手册特别提醒过这点容易出错）。
4. **交叉校验（已完成，而且发现手册模板和真实文件有出入）**：在你这台机器上找到了真实安装的 SOLIDWORKS 2026，对比了官方 `...\lang\chinese-simplified\sldmaterials\solidworks materials.sldmat` 和系统默认生成的自定义材料种子文件后，发现手册 1.2 节 B 小节的社区模板有两处和真机不一致，已按真实结构修正：
   - 根节点要用 `mstns` 前缀：`<mstns:materials xmlns:mstns="http://www.solidworks.com/sldmaterials" ...>`，不是裸 `xmlns=""`；带了 mstns 前缀后，下面的 `classification`/`material`/`physicalproperties` 等子节点不用再加前缀。
   - `physicalproperties` 下的数值字段**不带 `unit=` 属性**，就是纯 SI 数值（和手册模板里写的 `unit="N/m^2"` 这类属性不同）。
   - 编码上也和真机一致，存成了 **UTF-16（带 BOM）**，不是 UTF-8。
5. 修正后的文件已经直接放进你这台机器 SW 已注册的自定义材料目录 `C:\ProgramData\SOLIDWORKS\SOLIDWORKS 2026\自定义材料\VGD_Materials.sldmat`，**你已经确认重启 SW 后能找到**。

这个方法的好处是**可以批量生成、脚本化**，缺点是手册也提醒了：SW 没公开官方 schema，这套结构是社区反向工程出来的——好在这次直接拿你机器上的真实文件核对过了，不是纸上谈兵。

### 方法 A：GUI 建库（需要你在装了 SW 的电脑上做）

GUI 方法的意义不只是"重新做一遍"，更重要的是**用它导出的真实文件去校验方法 B 生成的 XML 结构对不对**（手册 1.2 节原话："正确做法是先用 GUI 建一个材料保存，再去核对社区模板"）。具体步骤见下面第四节，建议你先做这个，再拿产物和我生成的 `VGD_Materials.sldmat` 对比一下结构（标签名、嵌套关系、属性大小写），确认没问题后两个文件可以合并成一个库。

## 三、如何现在就用起来（方法 B 产物，当前这台机器已验证可用）

1. ~~打开 SW → 工具 → 选项 → 系统选项 → 文件位置 → 材料数据库，添加路径~~ —— **这一步已经帮你做完**：你这台机器 SW 已经默认注册了 `C:/ProgramData/SOLIDWORKS/SOLIDWORKS 2026/自定义材料/` 这个路径（打开你的默认自定义材料种子库用的就是这个目录），`VGD_Materials.sldmat` 已经直接放进去了，不用你再手动添加路径。
2. **重启 SW**（材料库是启动时加载的，不重启不会刷新）——你已经确认重启后能找到。
3. 任意打开一个零件 → 右键材质（或 FeatureManager 树里的"材质"节点）→ 编辑材料 → 左侧树展开 **自定义材料** → 能看到 `VGD_Materials` 库，下面是四个分类、十个材料（碳纤维板、**黑色玻璃纤维板**、铝合金三种、3D打印材料五种）。
4. 双击任意材料，核对右侧"属性"页里的数值是不是和手册 1.5 节表格（或下面第四节黑色玻纤板的估计值说明）一致，重点看密度那一栏的小数点位置，单位是 kg/m³。
5. 如果以后要更新库：直接改 `d:/asm_lab/VGD机械设计手册/材料库交付/VGD_Materials.sldmat` 这份源文件，改完重新拷贝覆盖到上面那个 ProgramData 路径，再重启 SW 即可——这样源文件和部署文件保持一致，方便你以后对比 diff。

## 四、方法 A：GUI 建库详细步骤（给你录屏/截图用）

下面每一步我都写了"建议截图/录制的画面"，照着这个顺序录，出来就是一条完整教程。

1. **打开任意零件** → 在左侧 FeatureManager 设计树里找到"材质 <未指定>"节点 → 右键 → **编辑材料**。
   - 📸 截图点：右键菜单弹出、"编辑材料"选项高亮的瞬间。
2. 弹出**材料对话框**，左侧是树状分类（SOLIDWORKS 材料 / 自定义材料）。
   - 📸 截图点：对话框整体布局，标注"左侧材料树 / 右侧属性-外观-剖面线三个选项卡"。
3. 右键左侧树的 **自定义材料（Custom Materials）** → **新建库** → 命名为 `VGD_Materials` → 保存位置选一个你记得住的文件夹（建议先存到这个 `材料库交付` 文件夹里，方便和我生成的文件对比）。
   - 📸 截图点：右键菜单 →"新建库"→ 保存对话框（文件名、路径）。
4. 在刚建好的 `VGD_Materials` 库上右键 → **新建类别**，依次建三个：`VGD_碳纤维板`、`VGD_铝合金`、`VGD_3D打印材料`（和方法 B 的分类名保持一致，方便后面合并）。
   - 📸 截图点：右键 →"新建类别"→ 输入类别名。
5. 在某个类别下右键 → **新建材料**，比如先建 `VGD_铝合金` 下的 `6061-T6`：
   - a. **属性**选项卡：材料模型下拉选 **Linear Elastic Isotropic**（铝材用这个；碳板要选 Orthotropic，TPU 要选超弹性模型——这三种模型切换的界面差异建议专门录一段）。
   - b. 逐个填数值：密度、弹性模量、泊松比、剪切模量、抗拉强度、屈服强度、热膨胀系数、热导率、比热——照手册 1.5② 表格 6061-T6 那一列填，**单位看清楚对话框里标的是 Pa 还是 MPa 还是 GPa**（这是最容易填错的地方）。
   - c. **外观**选项卡：可选，给个颜色方便渲染图区分材质（比如铝给银灰色、碳板给黑色）。
   - d. **剖面线**选项卡：可选，工程图剖视图填充样式，铝材/碳板用不同图案区分。
   - 📸 截图点：属性选项卡填完整的画面（能看清每个字段和数值）、材料模型下拉展开的画面、外观选项卡选色界面。
6. 点 **应用** → 点 **保存**（或关闭对话框时提示保存）。
   - 📸 截图点：保存成功后，左侧树里能看到 `6061-T6` 已经挂在 `VGD_铝合金` 分类下。
7. 重复步骤 5-6，把手册 1.5 节里其他材料都建完（6061-T4、6061-O、碳纤维板、PLA 几种、TPU 几种）。
8. 全部建完后，到文件系统里找到生成的 `VGD_Materials.sldmat`（路径就是步骤 3 里你选的保存位置）。
   - 📸 截图点：文件资源管理器里这个 `.sldmat` 文件的位置。
9. **校验环节**：用 VS Code 或记事本打开这个 GUI 生成的 `.sldmat`，和我生成的 `VGD_Materials.sldmat` 并排对比：
   - 根节点命名空间是不是 `xmlns="http://www.solidworks.com/sldmaterials"`；
   - 层级是不是 `materials → classification → material`；
   - `material` 的属性名是不是小写 `name=""` `matid=""`；
   - `physicalproperties` 下字段标签是不是一致（`EX/NUXY/GXY/DENS/SIGXT/SIGYLD` 等）。
   - 📸 截图点：两个文件并排对比的画面，这段很适合做教程里"为什么要校验"的讲解素材。

## 四-B、实操示例：黑色玻璃纤维板（照这个录屏效果最好）

这个材料比铝合金更适合当教程的"主角"，因为它同时能演示**外观颜色（黑色）**和**数据不全时怎么标注来源**这两个知识点。下面是专门为录屏准备的分镜脚本，照这个顺序点一遍就是一条完整的"从零建一个新材料"演示：

> ⚠️ 先说清楚这个材料的数据来源：手册 1.5 节目前**没有**玻璃纤维板的数据表，下面的数值是按常见黑色环氧玻纤层压板（G10/FR4，机器人/云台结构件常用的黑色玻纤板就是这类材料）的公开资料给的**估计值**，不是从手册原文抄的，也没有实测或厂商 TDS 核实。录完教程后，如果你们真的要用这个材料做结构件，务必按手册 1.3 节的优先级去找真实数据替换。

| 字段 | 估计值 | 单位 | 说明 |
|---|---|---|---|
| 质量密度 | 1800 | kg/m³ | G10/FR4 常见密度 1.7~1.85 g/cm³ 取中间偏上 |
| 弹性模量 | 22 | GPa | 面内拉伸模量常见区间 17~24 GPa 取中点 |
| 泊松比 | 0.13 | — | 玻纤环氧层压板常见估计值，🔶 低可信度 |
| 抗拉强度 | 310 | MPa | 面内拉伸强度常见区间 300~320 MPa |

**录屏分镜（建议用 Win+Alt+R 或 OBS 开始录制后再做下面动作）**：

1. 打开任意零件 → 右键材质 → 编辑材料 → 左侧展开 **自定义材料 → VGD_Materials**（这里直接展示我已经用方法 B 建好的库，顺带讲一句"这是脚本批量生成的，下面演示手动再建一遍"）。
   - 📸/🎬：展示左侧树已有的 `VGD_玻璃纤维板` 分类和里面的黑色玻纤板材料，双击打开，念一下右侧密度/模量数值。
2. 切换到 **自定义材料** 根节点 → 右键 → **新建类别** → 命名 `VGD_玻璃纤维板_手动` （带"_手动"后缀避免和已有分类重名冲突）。
   - 🎬：右键菜单 →"新建类别"→ 输入类别名的全过程。
3. 右键这个新类别 → **新建材料** → 命名 `黑色玻璃纤维板(手动示例)`。
   - 🎬：右键 →"新建材料"→ 命名输入框。
4. **属性**选项卡：材料模型下拉选 **Linear Elastic Isotropic**（玻纤板初算时按各向同性近似处理，和手册碳板的处理思路一致——这里可以顺带提一句"精确校核要用正交各向异性，这里是简化"）。
   - 🎬：下拉框展开、选中 Linear Elastic Isotropic 的瞬间。
5. 逐个填上表四个字段：密度 1800、弹性模量 22（注意单位，如果对话框要求 Pa 就填 22000000000）、泊松比 0.13、抗拉强度 310（同样注意 MPa/Pa 换算）。
   - 🎬：填数值时特意停顿，字幕标注"单位看清楚，这是最容易填错的地方"。
6. 切到 **外观** 选项卡 → 选颜色 → 直接拖到纯黑或输入 RGB `1A1A1A`（比纯黑 `000000` 稍微柔和，渲染图里不死黑）。
   - 🎬：颜色选择器拖动/输入 RGB 值的画面，这是这条视频最适合展示的"外观设置"知识点。
7. **剖面线**选项卡：选一个和碳板/铝材不同的图案（比如 ISO 剖面线），方便工程图里一眼区分材质。
   - 🎬：剖面线下拉选择画面。
8. 点 **应用 → 保存**。
   - 🎬：保存成功后左侧树出现 `黑色玻璃纤维板(手动示例)` 挂在新类别下。
9. 收尾对比：打开资源管理器，找到 GUI 生成的 `.sldmat` 文件，和我已经写好的 `VGD_Materials.sldmat` 里 `VGD_玻璃纤维板` 那段并排放一起看一眼结构是否一致（这段对应本说明书第四节第 9 步的校验逻辑，用黑色玻纤板这个新例子再做一次，观众印象更深）。

这条录完之后，你可以把 GUI 手动建的这份和脚本生成的那份合并成一份最终交付库，或者直接留着脚本生成的那份（已经部署好、已验证能用），GUI 这份只作为教程演示/校验用。

## 五、分享给队友：两种途径怎么分享、队友怎么装

无论方法 A 还是方法 B 做出来的，最终都是同一种东西——一个 `.sldmat` 文件，**分享方式是一样的**，区别只在"文件是怎么来的"。给队友的安装说明可以直接摘这一段发群里：

### 队友安装步骤（可直接转发）

1. 拿到 `VGD_Materials.sldmat` 文件（群文件 / 共享盘 / U 盘都行）。
2. 打开 SW → 工具 → 选项 → 系统选项 → 文件位置 → 材料数据库 → 点"添加"，把文件放的那个文件夹路径加进去（或者直接把文件拷到列表里已有的某个路径下）。
3. **重启 SW**（必须重启，材料库不是实时加载的）。
4. 打开任意零件 → 编辑材料 → 左侧自定义材料里能看到 `VGD_Materials` 库，直接选材料用就行，不用重新输数值。

### 两种分发渠道可以都试

- **渠道 1：Git 仓库（推荐，现在已经是主渠道）**：`git clone https://github.com/chuvgd/VGD_mech_design.git`，材料库在 `材料库交付/VGD_Materials.sldmat`。好处是有改动历史、能看 diff、支持多人同时改（见第七节），以后更新库只要 `git pull` 就行，不用等人在群里发文件。
- **渠道 2：群文件 / 共享盘**（临时应急用）：直接把 `VGD_Materials.sldmat` 发群里或放团队共享文件夹，队友按上面 4 步装。这个渠道**不记录历史、容易被旧文件覆盖新文件**，建议只在队友还没装 git/没权限访问仓库时临时用一下，装好 git 后尽快切回渠道 1。

## 六、后续维护提醒

- **改数值**：改哪个材料就改对应 `<physicalproperties>` 下的字段值，注意单位（Pa / kg·m⁻³ / K⁻¹），别把 GPa 当 Pa 填（比如 68.9 和 68900000000 这种错法最常见）。
- **加新材料**：**不要直接改完 XML 就完事**——按第七节的 git 流程走（建分支 → 改 → PR → merge），不要直接在 main 分支上改完就推送，避免和别人正在改的内容冲突。
- **升级可信度**：手册 1.3 节的实测数据（密度排水法、三点弯测模量等）出来以后，直接覆盖对应字段，并在手册 1.5 节表格里把可信度标记从 ⚠️ 改成 ✅。
- **碳板正交各向异性**：现在库里碳板是"初算用各向同性近似"，等拿到真实 TDS（铺层、EX/EY/EZ 等九个弹性常数）以后，照手册 1.2 节模板加一个 Orthotropic 的碳板材料，并在建材料时用参考几何体指定纤维方向（这步必须在 GUI 里做，XML 没法指定"哪个面是纤维方向"）。

## 七、协作扩库流程（已用 Git 实现，仓库：chuvgd/VGD_mech_design）

之前这里写的是一套手搓的"登记表占号"方案（没装 git 时候的权宜之计）。现在这台机器已经装好了 **Git** 和 **GitHub CLI（gh）**，并且把整个 `VGD机械设计手册` 文件夹推到了 chuvgd 组织下的私有仓库，**材料库的多人协作直接交给 git 处理**，不用再手动登记占号——这是本节改动的核心。

### 7.0 仓库信息 & 这台机器上的环境

- **远程地址**：`https://github.com/chuvgd/VGD_mech_design.git`（私有仓库，chuvgd 组织下新建的，之前没有现成仓库对应机械设计手册）
- **仓库结构**：整个 `VGD机械设计手册/` 就是仓库根目录，章节 `.md` 在根目录，材料库在 `材料库交付/` 子目录下。
- **这台机器已经做好的环境配置**（如果在别的机器上克隆，需要重复这些步骤，见 7.1）：
  - 装了 Git 2.56（`winget install --id Git.Git -e`）和 GitHub CLI（`winget install --id GitHub.cli -e`）。
  - 国内直连 GitHub 不稳定，走的是本机 `http://127.0.0.1:7897` 本地代理；而且代理下 HTTP/2 协商经常卡住导致 push 失败（`curl 52 Empty reply from server`），已经通过 `git config --global http.version HTTP/1.1` 强制用 HTTP/1.1 解决，**push 卡住的话先检查是不是这个问题**。
  - `.gitattributes` 里把 `*.sldmat` 标注成 `text working-tree-encoding=UTF-16LE-BOM`——这一步是关键：`.sldmat` 本质是 UTF-16LE 带 BOM 的 XML（和 SW 官方文件一个格式），不标注的话 git 会把它当二进制处理，没法看 diff，更没法自动合并；标注错了编码（比如漏了 `-BOM`）还会导致 checkout 出来的文件 BOM 丢失或字节序变成大端，SolidWorks 打不开。**这个坑已经踩过并修好了，新增材料库类文件时记得照此设置**。
  - 已经**实测过**两个分支各自新增不同材料后 `git merge` 的效果：自动合并成功，XML 结构正确，文件的 UTF-16LE+BOM 编码也完好无损（测试用的材料改完就删了，不影响正式库）。

### 7.1 队友第一次加入

1. 找仓库所有者（或 chuvgd 组织管理员）把自己加进仓库协作者 / 确认组织成员默认有访问权限（仓库是私有的，没权限的话 clone 会报 404）。
2. 自己电脑装 Git：Windows 上 `winget install --id Git.Git -e`；再装 GitHub CLI 方便登录：`winget install --id GitHub.cli -e`。
3. `gh auth login --web`，按提示打开浏览器网址、输入一次性代码完成授权（国内网络可能需要开代理，参考 7.0 的配置）。
4. `gh auth setup-git`（让 git 的 push/pull 也用这个登录状态，不用额外配密码）。
5. 配置自己的 git 身份（每人在自己机器上配自己的，提交记录能看出是谁改的）：`git config --global user.name "<你的称呼>"` 和 `git config --global user.email "<你的邮箱>"`，括号里换成自己的信息。
6. `git clone https://github.com/chuvgd/VGD_mech_design.git`，clone 下来就是整本手册 + 材料库。

### 7.2 新增一个材料的标准流程（SOP，基于分支 + Pull Request）

1. `git pull origin main`，保证本地是最新的。
2. `git checkout -b add-material-黑色玻纤板`（分支名带上材料名，方便认领和回溯）。
3. 建材料：GUI（方法 A，见第四节）或直接改 XML（方法 B）都行，`matid` 直接往当前文件里最大值 +1 编（不用再去登记表占号——这就是 git 的意义：**就算两人同时各挑了一个新 matid，只要不是刚好选中同一个数字，git 完全能自动合并；哪怕真撞了号，PR 阶段肉眼一看就能发现**，不需要靠人工登记表去"预防"撞号）。
4. 顺手在 `材料登记表.md` 里补一行（现在这张表的作用从"防冲突登记"降级成"材料清单速查表"，方便不想开 SW 翻材料树的人也能看一眼库里有什么）。
5. `git add -A && git commit -m "feat: 新增黑色玻纤板"`。
6. `git push -u origin add-material-黑色玻纤板`。
7. 去 GitHub 网页（或用 `gh pr create`）开一个 Pull Request，找队友 review——review 时重点看：`matid` 有没有和 main 上已有材料重复、可信度标记（✅/⚠️/🔶）填没填、数据来源写没写清楚。
8. Review 通过后 merge 到 main。
9. 其他队员 `git pull origin main` → 把更新后的 `VGD_Materials.sldmat` 拷到本机 SW 的自定义材料目录（这台机器是 `C:/ProgramData/SOLIDWORKS/SOLIDWORKS 2026/自定义材料/`，其他人的路径可能不同，参考第三节第 1 步） → 重启 SW 验证。

### 7.3 真遇到合并冲突怎么办

`.sldmat` 本质是纯文本 XML，git 的三方合并（ort 策略）处理"两人在文件不同位置各加一段"的情况非常擅长——已经实测过完全自动合并、不需要人工介入。真正会冲突的情况只有"两人编辑了同一段内容"（比如都去改了同一个已有材料的数值），这时候 git 会在文件里插入 `<<<<<<<` / `=======` / `>>>>>>>` 冲突标记，用 VS Code 打开（VS Code 自带冲突高亮和"接受当前/接受传入/接受两者"按钮）手动选一下就行，解决完 `git add` 再 commit 继续合并。

### 7.4 命名与分类约定（减少混乱）

- 新分类统一加 `VGD_` 前缀（已有：`VGD_碳纤维板`、`VGD_玻璃纤维板`、`VGD_铝合金`、`VGD_3D打印材料`），新建分类前先看登记表最后一节的"分类清单"，能并入已有分类就不要开新的。
- 材料名称里带上关键区分信息，比如厂商/牌号/状态（`6061-T6`）、估计值要注明`(估计值)`、初算近似要注明`(初算用)`——方便别人一眼看出能不能直接拿去做精确校核。
- 可信度标记（✅/⚠️/🔶）**必须填**，这是手册 1.3 节定的规矩，PR review 时如果发现没填，直接打回去让补上。
- 分支名、commit message 都带上材料名或改动内容，方便以后 `git log` 翻历史找某个材料是谁、什么时候加的、为什么改的。
